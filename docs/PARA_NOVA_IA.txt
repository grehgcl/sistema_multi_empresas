1. WHATSAPP EVOLUTION - SISTEMA MULTI-INSTÂNCIA 📱
-----------------------------------------
- Provedor: Evolution API (http://163.176.218.131:8080)
- Instância Padrão: seeagende
- Instância Própria: Cada empresa Business/Enterprise
- Confirmação de Agendamento: Enviada automaticamente
- Lembrete 24h: Job automático às 09:00
- Cancelamento: Notifica o cliente
- Conclusão: Agradecimento automático
- Telefone do Dono: Aparece em todas as mensagens
- Endereço: Aparece nas mensagens
- Formatação: (XX) XXXXX-XXXX

2. NOVOS CAMPOS NO BANCO
-----------------------------------------
whatsapp_instance VARCHAR(100)
whatsapp_connected BOOLEAN DEFAULT FALSE
whatsapp_number VARCHAR(20)
whatsapp_connected_at TIMESTAMP
whatsapp_proprio_habilitado BOOLEAN DEFAULT FALSE

3. SUPER ADMIN - DASHBOARD COMPLETO 🏢
-----------------------------------------
- Cards com métricas (empresas, donos, clientes, agendamentos, faturamento)
- Lista completa de todas as empresas
- Status do trial (dias restantes, expirado, ativo)
- Gerenciar usuários (nome, email, telefone, role, senha, comissão)
- Filtrar empresas por nome em tempo real
- NOVO: Coluna 💬 WhatsApp com controle de habilitação

4. SUPER ADMIN - CONTROLE WHATSAPP
-----------------------------------------
- Habilitar/desabilitar WhatsApp próprio de qualquer empresa
- Ver status de todas as empresas
- 3 estados: 🔴 OFF, 🟡 PEND, 🟢 ON, 🔒 [plano]

5. DONO - WHATSAPP EXCLUSIVO 👨‍💼
-----------------------------------------
3 cenários:
- Plano não permite → Tela de upgrade
- Plano permite mas Super Admin não habilitou → "Aguarde o administrador"
- Tudo OK → Pode criar instância e conectar WhatsApp

Funcionalidades:
- Criar instância na Evolution API
- Escanear QR Code com WhatsApp pessoal
- Ver status de conexão
- Desconectar WhatsApp

6. SISTEMA DE ACESSOS 📊
-----------------------------------------
- Registro automático de acessos no login
- Captura de IP e User-Agent
- Estatísticas por empresa (total, hoje, último acesso)

7. CORREÇÃO DE BOOLEANOS 🎯
-----------------------------------------
- PostgreSQL: true/false, SQLite: 1/0
- Função isAberto() para compatibilidade

8. CORREÇÃO DE .toFixed() 🎯
-----------------------------------------
- PostgreSQL retorna strings
- parseFloat() antes de toFixed()

9. PRESERVAÇÃO DE HORÁRIO NA AGENDA 🎯
-----------------------------------------
- Horário é mantido ao selecionar serviço
- Próximo horário disponível se o selecionado não estiver disponível
